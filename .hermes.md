# JobRadar / Loker Aggregator — Project Context

Pribadi aggregator lowongan kerja. 2 output dari 1 pipeline: Telegram (notif IT-only) + Web publik (semua job). Target karier: AI Engineer.

## Root
`/Users/ferrelganendra/Loker Scraper/loker-agg`

## Struktur
- `main.py` — orkestrator: scrape → classify → upsert DB → dump `out/jobs.json` → notif Telegram
- `db.py` — SQLite (`loker.db`), `upsert_jobs`, `all_rows()`, `backfill_glints_from_desc()`
- `filter.py` — `classify()`, `_extract_salary()`, `is_foreign` logic, ID_CITIES
- `scraper/html/*.py` — per-source scraper (glints, remoteok, arbeitnow, remotive, jobicy, linkedin, jobstreet, hn)
- `web/` — statis frontend: `index.html`, `style.css`, `app.js`, `data/jobs.json`, `fonts/`, `DESIGN.md`
- `.env` — TELEGRAM_BOT_TOKEN dsb (jangan pernah commit/print)

## Command penting
```bash
env -u PYTHONPATH .venv/bin/python3 main.py   # jalankan pipeline (WAJIB env -u PYTHONPATH)
cp out/jobs.json web/data/jobs.json            # setelah main.py, update web data
cd web && env -u PYTHONPATH python3 -m http.server 8124   # serve web lokal
```

## Gotcha KRITIS
- **PYTHONPATH leak**: Hermes injek PYTHONPATH ke venv → rusak urllib3/pydantic. SEMUA command wajib `env -u PYTHONPATH`.
- **Mac py3.9.6**: type hint `str | None` GAGAL. Pakai `Optional[str]`.
- `.venv` = py3.9.6 (requests, bs4, lxml, playwright). System python punya fontTools+brotli.
- **Jangan overwrite `web/data/jobs.json` manual** — selalu dari `cp out/jobs.json` (biar konsisten DB).
